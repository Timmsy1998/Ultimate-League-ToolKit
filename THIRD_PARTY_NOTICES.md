## PenguLoader

[PenguLoader](https://github.com/PenguLoader/PenguLoader)'s `core` project
(vendored as a pinned git submodule at `native/vendor/pengu-loader`, tag
`v1.1.6`). PenguLoader's own separate loader application and plugin catalog
are not included or used — only its `core` DLL, which ULTK's own code
installs, configures, and removes.
